# Hola, soy Carlos Díaz Salazar 👋

Construyo herramientas que resuelven problemas reales de mi propio negocio: un e-commerce de venta contraentrega en Perú, Ecuador y España, donde **WhatsApp es todo el canal de venta**.

Programo **con IA todos los días** (Claude Code, agentes) y me hago cargo de lo que sale a producción: lo despliego, lo monitoreo y lo arreglo cuando se rompe.

### 🛠️ Lo que he construido

| Proyecto | Qué resuelve | Stack |
|---|---|---|
| [**pitstore-watcher**](https://github.com/carju10-max/pitstore-watcher) | Vigilante de pedidos 24/7: detecta cada pedido nuevo de Shopify y avisa por Telegram con el mensaje de confirmación de WhatsApp listo para enviar. | Python · GitHub Actions · Shopify API · Telegram |
| [**aldoklio-analyzer**](https://github.com/carju10-max/aldoklio-analyzer) | Separa una canción en pistas (voz, batería, bajo…) con IA y detecta tonalidad, BPM y acordes. [**Demo en vivo**](https://huggingface.co/spaces/CarlosDiazSalazar/aldoklio-analyzer) | Python · PyTorch · Demucs · Gradio · HF Spaces |
| [**bankia-platform**](https://github.com/carju10-max/bankia-platform) | Plataforma de IA para un banco ficticio: gateway, RAG y agentes, con seguridad y gobierno de datos. *En construcción.* | FastAPI · LangGraph · Claude · pgvector |

### 🧰 También construí (código privado, con datos de clientes)
- **CRM de pedidos** (FastAPI): por producto y por tienda, con plantillas de WhatsApp por estado, alertas de direcciones que van a fallar y recordatorio de reentregas.
- **Puntaje de riesgo de entrega**: lee el historial del comprador en la plataforma logística y etiqueta solo los pedidos riesgosos antes de despachar.
- **Panel de rentabilidad**: cruza el gasto real de Meta Ads por anuncio con las entregas y muestra el ROAS verdadero, no el del administrador de anuncios.
- **Scrapers** de la Biblioteca de Anuncios de Meta y de Dropi para investigar productos ganadores.
